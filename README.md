Sudoku Solver

Description

A C++ based Sudoku Solver that automatically solves Sudoku puzzles using the Backtracking Algorithm.

Features

- Solves 9x9 Sudoku puzzles
- Uses Backtracking Algorithm
- Validates row, column and subgrid constraints
- Displays solved Sudoku grid

Technologies Used

- C++
- VS Code
